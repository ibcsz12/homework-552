# Авто ДЗ — Mini App

Интерфейс для Telegram-бота «Авто ДЗ». Хостится на GitHub Pages, логику выполняет бот на ПК.

## Настройка

1. Репозиторий должен быть **публичным**.
2. Settings → Pages → Source: `Deploy from a branch`, branch `main`, folder `/ (root)`.
3. Заполни `CONFIG` в `js/app.js` (ник и название репозитория).

Сайт будет доступен по адресу:
`https://<user>.github.io/<repo>/`

Роль задаётся параметром в URL, бот использует свою:
- админ: `?role=admin`
- ИИ-доступ: `?role=ai`
- ученик: `?role=user` (или без параметра)

## Фон

Положи картинки (jpg, png, webp, gif) в папку `background/` в корне репозитория.
Они подтянутся автоматически, одна выбирается случайно при каждом открытии.
Если картинок нет, используется градиент.

## Структура

- `index.html` — разметка
- `css/style.css` — стили
- `js/app.js` — логика, отправка действий боту, загрузка фона
- `background/` — фоновые картинки
- `images/icons/` — иконки (пока не используются, эмодзи)
